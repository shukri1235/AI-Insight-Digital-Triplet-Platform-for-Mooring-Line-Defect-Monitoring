PDF report templates for Mooring Twin.
One <id>.json per template (id: lower-case letters, digits, - and _). Edit them in the app
(System -> Report templates) or here; every field is optional (see default.json for all of them).
logo: a PNG or JPG file in this folder. font: auto, helvetica, times, or the path of a .ttf file
(set font_bold too). Colours are #RRGGBB.
